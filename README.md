# Autonomous Tank System

An autonomous robot built around a Frigidaire retro mini fridge on a
tank-tread chassis. It follows or flees from a detected person, avoids
obstacles, and is controlled from a Steam Deck via a browser-based web UI
over a WiFi hotspot the robot itself broadcasts.

This README is being filled in as the codebase is packaged for this
repository; see the commit history for the order the subsystems were added
in. A full architecture writeup, setup instructions, and known issues
section land in a later commit.
